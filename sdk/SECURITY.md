# Security and support

This is an experimental, unofficial station-reading SDK. It has no promised support or security-response service and no npm release. Do not use it for flood-warning or emergency decisions.

Do not post credentials or sensitive details in public issues. Non-sensitive reproducible defects can be reported in the [repository issue tracker](https://github.com/vaishakh3/ea-flood-sdk/issues). Voxgig supplies the generator; it is not responsible for maintaining this independently published SDK.
